# وصفتي - نظام الوصفات الطبية الذكي

نظام متكامل لإدارة الوصفات الطبية يساعد الأطباء على إنشاء وصفات آمنة مع فحص تلقائي للتداخلات الدوائية والموانع.

## الميزات الرئيسية

- **إدارة شاملة للمرضى**: حفظ البيانات الطبية والأدوية الحالية والحساسيات
- **قاعدة بيانات الأدوية**: معلومات تفصيلية عن الأدوية والجرعات والتداخلات
- **اقتراحات ذكية**: اقتراح أدوية مناسبة بناءً على الأعراض والتشخيص
- **فحص التداخلات**: فحص تلقائي للتداخلات الدوائية والموانع
- **سجل الزيارات**: حفظ كامل لجميع الزيارات والوصفات السابقة
- **واجهة عربية**: تصميم دارك مود احترافي بخط IBM Plex Sans Arabic

## المتطلبات

- Python 3.10.6

## التثبيت والتشغيل

### 1. تثبيت المكتبات المطلوبة

```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق

```bash
python app.py
```

أو

```bash
flask run
```

### 3. فتح المتصفح

افتح المتصفح وانتقل إلى:
```
http://127.0.0.1:5000
```

### 4. تسجيل الدخول

استخدم بيانات المستخدم الافتراضي:
- **اسم المستخدم**: admin
- **كلمة المرور**: admin123

## البيانات التجريبية

عند التشغيل الأول، سيقوم النظام تلقائياً بإنشاء قاعدة البيانات وإضافة بيانات تجريبية تشمل:

- **مرضى تجريبيون**: مريضان بملفات رقم P001 و P002
- **أدوية تجريبية**: 5 أدوية من فئات مختلفة (مسكنات، مضادات حيوية، إلخ)

جميع البيانات التجريبية موسومة بكلمة "تجريبي" ويمكن تعديلها أو حذفها.

## استخدام النظام

### إضافة مريض جديد

1. اذهب إلى قائمة المرضى
2. اضغط على "إضافة مريض جديد"
3. املأ البيانات المطلوبة (رقم الملف، الاسم، العمر، الجنس)
4. أضف الأدوية الحالية والحساسيات إن وجدت
5. احفظ البيانات

### إنشاء وصفة طبية

1. افتح ملف المريض
2. اضغط على "وصفة جديدة"
3. أدخل الأعراض والتشخيص
4. اضغط على "اقتراح أدوية مناسبة"
5. اختر الأدوية المناسبة من القائمة المقترحة
6. عدّل الجرعات والمدة والتعليمات حسب الحاجة
7. احفظ الوصفة

### إدارة الأدوية

1. اذهب إلى قائمة الأدوية
2. يمكنك البحث أو الفلترة حسب الفئة
3. لإضافة دواء جديد: اضغط "إضافة دواء جديد"
4. املأ المعلومات: الاسم، الفئة، الجرعات، التداخلات، الموانع

## ملاحظات مهمة

- هذا النظام هو أداة مساعدة للأطباء ولا يغني عن الحكم الطبي المهني
- جميع البيانات التجريبية هي لأغراض التدريب فقط
- يجب مراجعة جميع الاقتراحات والتحذيرات من قبل الطبيب المختص
- النظام يعمل محلياً ولا يتطلب اتصال بالإنترنت بعد التثبيت

## استكشاف الأخطاء

### المنفذ مستخدم بالفعل

إذا ظهرت رسالة أن المنفذ 5000 مستخدم، يمكنك تغيير المنفذ في ملف `app.py`:

```python
app.run(debug=True, host='127.0.0.1', port=5001)
```

### خطأ في قاعدة البيانات

إذا واجهت مشاكل في قاعدة البيانات، احذف ملف `instance/wasfati.db` وأعد تشغيل التطبيق لإنشاء قاعدة بيانات جديدة.

### الخط لا يظهر بشكل صحيح

تأكد من وجود ملفات الخط في المسار:
```
C:\UPath\Wasfati\static\assets\fonts\
```

إذا لم تكن موجودة، انسخ ملفات خط IBM Plex Sans Arabic إلى هذا المجلد.
